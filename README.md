# Virtual Assistant Portfolio

A responsive, single-page portfolio site built with plain HTML, CSS, and JavaScript. It can be hosted for free with GitHub Pages.

## Preview locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Personalize the site

Before publishing, edit `index.html` and replace the sample details with your own:

- Replace `Your Name` and all bracketed prompts with your bio, availability, and real work examples.
- Update the contact links near the bottom: email, WhatsApp, LinkedIn, and Calendly.
- Change or remove sample pricing, testimonials, client results, and experience claims. Only publish details that are true for you.
- Add your own photos or work samples under `assets/images/` and link them from the page.

The color palette and layout are in `css/style.css`. The profile chooser, scrolling rows, navigation highlight, and plan selection behavior are in `js/script.js`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload or push the contents of this folder. Keep `index.html` at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for the Pages deployment to finish. GitHub will show the published URL in the Pages settings.

This is a static site, so it needs no build step or server. Changes pushed to the selected branch will be published by GitHub Pages.

## Files

```text
index.html       Page content
css/style.css    Layout, colors, and responsive styles
js/script.js     Small interactive behaviors
assets/images/   Your photos and portfolio images (add as needed)
```
